# BladePlex

**BladePlex** is a modern, open-source media discovery and request platform built for Plex, Jellyfin, and Emby users.

Instead of simply requesting movies and TV shows, BladePlex is designed to become the **homepage for your personal streaming server**—bringing together intelligent discovery, curated collections, trending content, and seamless request management into one beautiful interface.

BladePlex integrates directly with your existing media ecosystem including **Plex**, **Jellyfin**, **Emby**, **Sonarr**, and **Radarr**, while introducing an expanding set of discovery features that make finding something to watch just as enjoyable as watching it.

---

# Features

## Media Discovery

- Native homepage featuring curated content shelves
- Official MDBList integration
- United States Daily Streaming Charts
- Native "View All" pages with infinite scrolling
- Ranked movie discovery
- Cached streaming charts for fast browsing
- Planned seasonal and curated collections
- Beautiful streaming-service-inspired interface

## Request Management

- Movie and TV requests
- Individual season requests
- Granular approval workflow
- Availability tracking
- Blocklists and watchlists
- Smart request status indicators

## Media Server Integration

- Plex
- Jellyfin
- Emby

Including:

- User authentication
- User import & synchronization
- Library scanning
- Availability detection
- Existing media recognition

## Automation

Native integration with:

- Sonarr
- Radarr

Additional integrations are planned.

## Administration

- Granular permissions
- Multiple user roles
- SMTP configuration
- Notification agents
- PostgreSQL
- SQLite

## Performance

- Server-side caching
- Intelligent TMDb hydration
- Native pagination
- Optimized API usage
- Efficient background refreshes
- Mobile-friendly interface
